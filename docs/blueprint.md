# **App Name**: T-Shawarma

## Core Features:

- Dynamic Menu Display: A high-fidelity digital menu showcasing culinary offerings with vivid photography and real-time updates.
- AI Flavor Navigator Tool: An AI assistant that uses reasoning as a tool to recommend dishes based on the customer's mood, past preferences, or dietary goals.
- Instant Table Booking: A streamlined interface for checking availability and securing reservations in real-time.
- Signature Dish Gallery: An immersive, horizontally scrolling showcase for the chef's most visually stunning creations.
- Interactive Location & Hours: Animated contact module featuring map integration and smart status indicators showing current opening state.
- Member Recognition Portal: A UI for recurring customers to see their past orders and favorited menu items.

## Style Guidelines:

- Primary color: Vibrant Crimson (#C8102E) to evoke passion and appetite, providing a bold presence against light backgrounds.
- Background color: Pearl White (#FDF9F9), a soft, heavily desaturated variant of the primary hue for a clean, professional aesthetic.
- Accent color: Sophisticated Berry (#BF1972), providing high contrast for secondary buttons and highlight text.
- Headlines use 'Playfair' (serif) for an elegant, high-end culinary feel. Body text uses 'PT Sans' (sans-serif) for warmth and superior readability in descriptions.
- Fine-line, minimalist culinary icons with subtle crimson strokes to maintain visual consistency without overwhelming the UI.
- A clean, asymmetrical grid that prioritizes white space and high-resolution food imagery, similar to a contemporary lifestyle magazine.
- Smooth parallax scrolling on imagery and elegant staggered fade-ins for menu categories as the user interacts.
